# Handoff — 2026-10-10

Where the Lattice project stands and what to do next. Read this first, then `docs/results/` for the evidence.

## Direction (owner's decision, 2026-10-03; unchanged)

Lattice is an **executable business spec plus a checker**. The owner states the rules, an LLM writes the code, Lattice verifies it, and the LLM repairs the code until it passes. Specs are now **drafted by an LLM from the owner's markdown** and reviewed by the owner in minutes. They are edited and asked about in **Lattice Studio**.

## Evidence so far (all in `docs/results/`, pre-registered where noted)

1. **The spec gate sets the quality bar.**
   - On the job scheduler, every model gated by the spec passed: Python with Opus, Fable, Haiku and Sonnet; and Go.
   - The prose-only Sonnet baseline failed 11 checks.
2. **Go, bare briefs (pre-registered):** spec + gate gave 0 findings, against prose 4 (Opus) and 8 (Sonnet), at +14–17% tokens. With detailed briefs the two tied, because the briefs already carried Lattice's lessons.
3. **Agents build only what the spec checks.** The spec gaps found here (background loops, the same-minute rule) were closed in spec v2.
4. **LLM-drafted spec (pre-registered):**
   - Blind, it agreed with the hand spec on 5/11 verdicts; after one answer, 8/11.
   - Every remaining disagreement is a real defect the hand spec missed.
   - Probe gaps: 2 against the hand spec's 5. The owner reviewed it in 2–3 minutes.
5. **Multiple databases:** the Go app passes spec v2 on SQLite, Postgres and MySQL; race mutants are caught. The ClickHouse demo passes, and its mutant is caught.
6. **`spec ask` (pre-registered):** 15/15 specified + 5/5 not-specified answers correct. Cost fell from $1.89 to $0.88 per 20 questions after the retrieval fix. One false "disagrees" remains.
7. **Incremental drafting (pre-registered):** the diff was exact and the contradiction was raised as a question, scoring 4/5 blind. The impact crash and the L011 false positive are fixed, and it ran clean post hoc.
8. **Studio end to end:** a verified cited answer; a chat change drafted, checked, accepted as commit a610959; labels and UI fixes re-verified.

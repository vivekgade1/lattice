## 4. Environment facts learned

- Docker Desktop must be running for the container probes; a driver venv (psycopg, clickhouse-connect,
  pymysql layered over the Lattice venv through a `.pth`) lives in the session scratchpad
  (`.../scratchpad/perfengines/perfvenv`); recreate with `uv venv` + `uv pip install` + a `.pth`.
- The Streak provider for drift/index arms is `build/streak` a0679e9 (the owner's `main` holds the scaffold:
  login 404). Probes operate directly on the path they are given: **always clone Streak into scratch**. An
  orchestrator re-run once pointed the G14 probe at the owner's checkout and left `perf.budget.json` and a
  rebuilt ignored `bin/streak-api`; both were cleaned and `git status` verified (only the owner's own
  `studio.toml` edit remains).
- Runners' tmp-left guards trip on leftover `lattice-cli-cwd-*` dirs in TMPDIR: use a fresh empty TMPDIR.
- The `claude` CLI subscription has a usage limit that was hit once; agent-run sessions must record
  NOT RUN on a limit error and never retry in a loop.

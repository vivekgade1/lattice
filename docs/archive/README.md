# Archive: superseded direction (2026-09 to 2026-10-03)

Documents of the earlier Lattice direction, an LLM-native language with generated code
(the vision, the Option-1 pilot, the language/Go/TS/importer design specs and plans, the
first UI handoffs). They are kept as the provenance of the experiments under `bench/` and of
the pre-registered results in `docs/results/`, and are **not** the current plan.

Current direction (owner's decision, 2026-10-03): an executable business spec plus a
checker, an LLM that writes and repairs the code, and Lattice Studio. Start with
`docs/HANDOFF-2026-10-10.md`, `-part2.md`, `HANDOFF-2026-10-11.md`, then
`docs/lattice-direction-executable-spec.md` and `docs/lattice-reference.md`.

Moved here on 2026-10-12 from `docs/superpowers/`, `docs/handoffs/`, `docs/lattice-vision.md`,
`docs/option1-handoff.md` and `docs/handoff-2026-09-30.md`; references to the old paths were
rewritten (`git log --follow` finds the history).

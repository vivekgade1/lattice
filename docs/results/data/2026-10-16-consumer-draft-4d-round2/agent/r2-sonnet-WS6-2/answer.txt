The provider `streak` renamed a response field on `GET /v1/habits` from `next_cursor` to `next`, and streak-widget still relies on `next_cursor`. I haven't changed anything. I also haven't read streak-widget's source, so the code locations below are for you to find.

**What broke**

- **Broken:** the response of `GET /v1/habits` used to be `items`, `has_more`, `next_cursor`. It is now `items`, `has_more`, `next`.
- **Affected import:** import #4 in streak-widget's contract, `GET /v1/habits`. It uses auth `token` as user `ann`, expects status 200, sends `limit` and `cursor`, and reads `items`, `has_more` and `next_cursor`.
- **Unaffected:** the request side (`limit`, `cursor`) is not reported as changed.

Start with `grep -rn next_cursor streak-widget/`.

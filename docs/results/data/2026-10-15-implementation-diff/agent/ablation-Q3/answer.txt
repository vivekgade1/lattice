- **Request:** The body is `{items: [{id, habit_id, date, note?}, ...]}`. It takes 1 to 100 items, and anything else returns 422 `validation_failed` with field `items` (code:internal/completions/routes.go:32, code:internal/completions/routes.go:64-67).
- **Several habits:** Each item carries its own `habit_id`. The handler looks up each habit, checking it belongs to the caller, so one request can span different habits (code:internal/completions/routes.go:93-100).
- **Processing:** Items run in order inside one transaction. Each item gets its own nested transaction (savepoint), so a rejected item writes nothing and doesn't stop the others (code:internal/completions/routes.go:79-106).

## Issues found (follow-ups)

1. **Impact label:** the two eve-cancel scenarios were labelled `contradiction`, but they are really `not_built_yet` (the app still allows the cancel). The labeller uses the rules linked to the whole scenario; it should use the rules behind the step whose expectation changed.
2. **Ask cost:** about 188k input tokens per question, because the full digest is resent uncached. Put the digest in the cached system prompt, or retrieve only the relevant elements.
3. **UI and changes:** pending changes made outside the chat aren't shown on load. The UI doesn't yet send `parent` follow-ups or cancel (the server supports both).
4. **ask --verify:** count a failure as "disagrees" only on the claim step; setup failures should be "inconclusive" (from the ask experiment).
